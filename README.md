## 🎨 Brand Identity & Visual Design System

The visual identity of BizAssist AI is adapted from the developer-led design system:

### 1. Mandatory Six-Colour Palette
- **Primary Green** (`#0B6839` / `bg-brand-primary`): Primary brand surfaces, navigation accents, primary action buttons, success states.
- **Accent Yellow** (`#FEE101` / `bg-brand-accent`): Visual highlights, selected states, AI assistant accents, key statistics.
- **Pink** (`#FF0080` / `bg-brand-pink`): Critical priority indicators, emergency alerts, distinctive badges.
- **Black** (`#000000` / `bg-brand-black`): Navigation backgrounds, high-contrast panels, dark surfaces, hard borders.
- **Off-White** (`#FFFBE8` / `bg-brand-offwhite`): Main reading surfaces, light dashboard layouts, background canvas.
- **White** (`#FFFFFF` / `bg-brand-white`): Content containers, table rows, cards, input surfaces.

### 2. Dual Typography System
- **Headings — Imbue**: Google Font `Imbue` (400, 500, 700, 800) for high-contrast editorial uppercase headings, numbers, and display identity.
- **Body & UI — Victor Mono**: Google Font `Victor Mono` for all navigation tabs, buttons, tables, forms, status badges, timestamps, code snippets, and metadata.

### 3. Design Philosophy
- **Bold. Minimal. Technical. Intelligent. Functional.**
- Hard borders (2px / 4px `#000000` or `#0B6839`), high contrast, no generic rounded bubble cards or purple AI gradients.

## 📋 Core Modules (All 8 PRD Modules Implemented)

1. **M-01: Authentication & User Management** (RBAC Customer, Agent, Admin + session management)
2. **M-02: Support Ticket Lifecycle System** (Open, Assigned, In Progress, Waiting, Resolved, Closed)
3. **M-03: AI Ticket Classification** (Category, urgency priority, sentiment vector, structured JSON)
4. **M-04: AI Response Generator** (Empathetic, Technical, Concise, Step-by-Step tones with human approval)
5. **M-05: AI Complaint Summarization** (Root cause and operational impact briefs)
6. **M-06: Knowledge-Based AI Chatbot** (Grounded RAG retrieval against verified docs + 1-click ticket escalation)
7. **M-07: Admin Analytics & Visualizations** (Volume trends, status distributions, priority matrices, agent SLA table)
8. **M-08: Ticket Assignment & Workload Balancer** (Agent active queues, manual/auto assignment, audit history)
